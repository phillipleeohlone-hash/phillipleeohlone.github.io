Step 1 · Look First

Start With a Scatter Plot

  • A regression line only makes sense if the points fall roughly along a straight line.
  • Put the variable you want to predict on the vertical axis. Here that is weight.
  • Ask two questions: is the cloud roughly linear? Does it go up or down from left to right?

Step 2 · The Correlation Coefficient

Computing r

  • First put both variables in standard units: how many SDs above or below the mean. The GIVEN code does this.
  • r is the mean of the products of the two columns in standard units (Chapter 15.1).
  • In standard units, the regression line is simply y = r · x.
  • Because r is less than 1, a player 1 SD above average in height is predicted to be fewer than 1 SD above average in weight.
  • Guess before you compute. Comparing your guess with the answer builds a feel for r.

The Regression Line
Find the slope and intercept, then use the line to predict. Steps 3–4.
Step 3 · Slope and Intercept

The Regression Line in Original Units

  • slope = r × SD of y ÷ SD of x
  • intercept = mean of y − slope × mean of x
  • The slope is in units of y per unit of x: here, pounds per inch.
  • The line always passes through the point (mean of x, mean of y).
Example with made-up numbers
# hours studied (x) and exam score (y)
r = 0.5
x_mean, x_sd = 10, 4
y_mean, y_sd = 70, 12

slope = r * y_sd / x_sd
# 1.5 points per hour
intercept = y_mean - slope * x_mean
# 55

Step 4 · Predicting

Using the Line to Predict

  • predicted y = slope × x + intercept
  • The same formula works on a whole column at once, giving a prediction for every row.
  • The GIVEN plot draws the line over the data, so you can see where each prediction comes from.
Continuing the made-up example
# predicted score after 12 hours
slope * 12 + intercept
# 73.0

Step 5 · Residuals

What a Residual Is

  • residual = actual value − predicted value
  • It is the vertical distance from a point to the line (the blue segments).
  • A point above the line has a positive residual. A point below it has a negative residual.
  • For the regression line, the residuals always add up to about 0.

Step 6 · Extrapolation

Predicting Outside the Data

  • The line was fit only to the data in the shaded range.
  • The line keeps going forever, but nothing tells us the relationship does.
  • Predicting far outside the range is extrapolation. It can give nonsense, like a negative weight.

  • Filtering rows: df[df['col'] == value] keeps the rows where the condition is True. != means "not equal to".
  • Selecting columns: df[['a', 'b']], with two pairs of brackets, keeps just those columns.
  • table.iloc[:, 0] is column 0 and table.iloc[:, 1] is column 1, whatever their names. The : means all rows.
  • So one function can fit a line to any two-column DataFrame: column 0 is x, column 1 is y.
Step 7 · Choosing a Line

A Line for Each Group

  • Split the data into groups, then fit a line to each group with the same formulas as Steps 2–3.
  • A function can return the slope and intercept together as an array: line[0] is the slope and line[1] is the intercept.
  • Use if / else to pick the right line for each prediction. Every branch must return.
Example with made-up shipping rates
def shipping_cost(weight, speed):
    if speed == 'overnight':
        return 3 * weight + 20
    else:
        return weight + 5

shipping_cost(4, 'overnight')  # 32
