Chapter 11 · Review

Steps of a Hypothesis Test

  • 1. Hypotheses. The null hypothesis is a specific chance model. The alternative hypothesis states that the null model is not correct.
  • 2. Test statistic. A number that summarizes how much the observed data differ from what the null model predicts.
  • 3. Observed statistic. Calculated from the actual study data.
  • 4. Null distribution. Simulate data under the null model, calculate the statistic for each simulation, and repeat many times.
  • 5. Compare. Is the observed statistic typical or unusual under the null model?
  • 6. p-value and conclusion. State whether the result is “consistent” with the model.

This lab walks through these steps once, using one real experiment. You used the same routine on the gacha game — here it is with two categories instead of four.

1.1 · 1.2 · Model and Hypotheses

The Model and the Hypotheses

  • A model is a set of assumptions about how data are generated, including assumptions about chance.
  • The null hypothesis is a specific chance model describing how the data were generated. It must be precise enough to simulate data.
  • The alternative hypothesis states that the null model is not correct. It usually does not explain why or how the model fails.
  • Emily was testing whether the practitioners' answers behave like chance, not whether TT works.

1.3 · 1.4 · Choosing a Statistic

Choosing a Test Statistic

  • A test statistic summarizes how much the observed data differ from what the null model predicts.
  • The statistic should align with the alternative hypothesis: unusually large or small values may indicate disagreement with the null model.
  • The observed test statistic is calculated from the actual study data.
  • For each candidate, ask: can it be negative? What values can it take?
Checklist for a statistic

• One number per dataset

• Can be computed for the real data and for each simulation

• Its possible values match the histogram you expect

1.7 · Simulating One Experiment

Simulating with sample_proportions

  • sample_proportions(n, probs) simulates n draws from categories with the given probabilities (they sum to 1).
  • It returns an array of the proportion in each category, in the same order as probs.
  • Every run gives different values — that is the chance variation we want to study.
  • np.random.seed(n) fixes the random state so everyone gets the same numbers.
In [ ]:
coin_proportions = np.array([0.5, 0.5])
ten_flips = sample_proportions(10, coin_proportions)
ten_flips   # e.g. array([0.6, 0.4])

1.8 · Repeating the Simulation

Simulating Many Times

  • Package one simulation into a function that returns one statistic.
  • Start with an empty array. In a for loop, compute one value and np.append it.
  • np.append returns a new array, so assign the result back to the variable.
  • When you do not use the loop variable, the loop just repeats the code a fixed number of times.
In [ ]:
def one_roll_is_six():
    return np.random.choice(np.arange(1, 7)) == 6

results = np.array([])
for i in np.arange(1000):
    results = np.append(results, one_roll_is_six())

1.8 · The Null Distribution

Visualizing the Simulated Statistics

  • The null distribution shows the values the test statistic could produce if the null hypothesis were true.
  • A histogram shows which statistic values are typical or unusual under the null model.
  • If the observed statistic is typical of the null distribution, the data are consistent with the null hypothesis.
  • If it is unusual, the data provide evidence against the null hypothesis and support the alternative.

1.9 · The p-value

The p-value

  • A p-value is the probability, assuming the null hypothesis is true, of obtaining the observed statistic, or one more extreme, in the direction of the alternative.
  • A small p-value means the observed result is unusual under the null model, i.e. statistically significant.
  • Conventional standards: below 5% is statistically significant; below 1% is highly statistically significant.
  • With a simulation, estimate it as the fraction of simulated statistics that are as extreme as the observed one. np.count_nonzero counts the True values in a boolean array.
In [ ]:
sims = np.array([1.2, 4.8, 0.3, 5.1, 2.2])
np.count_nonzero(sims >= 4.0) / len(sims)   # 0.4

1.10 · Conclusion

Stating a Conclusion

  • State whether the result is “consistent” with the model.
  • A small p-value is evidence against the null hypothesis; the result would be unusual if the null model were true.
  • Failing to reject the null hypothesis does not prove that it is true.
  • Rejecting a model does not explain why it failed or establish a cause.
  • Report the observed statistic, the p-value, and the null distribution so readers can evaluate the evidence.
