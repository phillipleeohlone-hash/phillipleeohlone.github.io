1.0 · Text

Strings Are Text

  • A string is any sequence of characters wrapped in matching quotes — 'single' or "double"
  • print() drops a space between comma-separated arguments automatically
  • Names can point at strings exactly like they point at numbers
In [ ]:
print("I <3", 'Data Science')

1.1 · String Methods

Calling Methods on Strings

  • Syntax: <string>.<method>(<args>)
  • .replace(old, new) swaps every occurrence and returns a new string — the original is untouched
  • Methods chain left to right, same as functions inside functions
In [ ]:
'train'.replace('t', 'ing').replace('in', 'de')

1.1 · A Quick Distinction

Functions vs. Methods

  • A function stands on its own — the value it works on goes inside the parentheses: max(a, b)
  • A method belongs to a value — it's called with a dot on the thing it acts on: a.replace(...)
  • Same idea, different anchor: both can chain, and both take arguments — the dot is the only tell
In [ ]:
# function: value goes inside ( )
max(abs(-5), abs(3))

# method: value comes before the dot
'train'.replace('t', 'ing')

When you're not sure which one you're looking at, check for the dot: no dot, it's a function; a dot right before the name, it's a method. The Python Reference Sheet labels each one.

1.2 · Converting Types

Converting Strings and Numbers

  • 8 + "8" raises an error — you can't add a number and text directly
  • int("10"), float("8"), and str(anything) convert between the two worlds
  • Ints and floats can be added to each other freely
In [ ]:
8 + "8"  # TypeError

2.3 · Elementwise Operations

Elementwise Operations

  • Arithmetic (+ − * ** /) applies itself to every element at once — no loop needed
  • np.round(array, decimals) rounds every element the same way
  • The result is always a new array, same length as the original

3.0 · A Building Block

Dictionaries

  • A dictionary maps key: value pairs, written inside curly braces
  • Every key is unique — looking one up (d["a"]) hands back its matching value
  • pd.DataFrame({...}) expects exactly this shape: keys become column names, values become the columns
In [ ]:
{
    "Population": population_amounts,
    "Year": years
}
# keys -> column names, values -> column data

Same dictionary, two jobs: on its own it's just a mapping; handed to pd.DataFrame, it becomes a table.

3.1 · Loading From Disk

Relative and Absolute Paths

  • "imdb.csv" is a relative path — read starting from wherever the notebook itself lives, not from the root of the computer
  • Same folder as the notebook → the plain filename is enough
  • A subfolder needs more of the path: "data/imdb.csv"; one folder up is "../imdb.csv"
In [ ]:
pd.read_csv("imdb.csv")
# same folder as this notebook -- no path needed

An absolute path — the full path from the filesystem root — always works too, but only on the computer it was written for. Relative paths are what let the same notebook run on your machine, a classmate's, and the grader's.
