1.1–1.2 · The Idea

What an A/B Test Compares

  • An A/B test compares two groups, A and B, to see whether they could come from the same underlying distribution.
  • It is also called a permutation test.
  • You will usually not be told to run one. Part of the skill is recognizing when it applies, then carrying out each step correctly.
  • Reading: textbook Chapter 12.1, A/B Testing, and Chapter 11.4, Error Probabilities.

2.3 · New Method: Overlaid Histograms

One Histogram per Group

  • Loop over df.groupby('col'). Each pass gives the group's label and that group's rows.
  • Call plots.hist once per group, on the same axes.
  • alpha=0.5 makes the bars see-through, so overlapping groups stay visible.
  • label= plus plots.legend() shows which color is which.
  • Use the same bins for both groups so they are comparable.
Example with a made-up table
# plants: one row per plant, with columns
# 'fertilized' (0 or 1) and 'height'
bins = np.arange(0, 30, 5)

for label, rows in plants.groupby('fertilized'):
    plots.hist(rows['height'], bins=bins,
               alpha=0.5, label=label)

plots.legend();

2.4 · Test Statistic

Choosing the Test Statistic

  • The test statistic compares the two groups with one number.
  • A signed statistic (one mean minus the other) has a direction. An absolute-value statistic does not.
  • The alternative hypothesis tells you which values of the statistic count as evidence against the null.
  • Think about which measures describe a distribution, and what the alternative says about them.

2.5–2.6 · New Method: Summary Tables

A Table of Group Means

  • groupby('col')['val'].mean() gives a Series whose labels are the groups.
  • Adding .reset_index() turns it into a regular table (DataFrame) with the group in its own column.
  • Rename the columns by assigning a list of names to .columns.
  • Read a value from the table by its column name and row position.

2.7 · New Method: Function Arguments

Functions That Take a Table and Column Names

  • The inputs (arguments) are names for things the function will be given: a table and the names of its columns.
  • Inside the function, use only those names. If you use an outside variable, the function stops working on any other table.
  • A column name stored in a variable goes in the brackets without quotes: tbl[val_col].
  • Test it on two different tables to be sure it is general.
Example: a different statistic
def max_by_group(tbl, label_col, val_col):
    return tbl.groupby(label_col)[val_col].max()

max_by_group(plants, 'fertilized', 'height')

2.9 · New Method: Collecting Results

Repeating with a Loop and np.append

  • Start with an empty array: np.array([]).
  • Each pass of the loop, add one result with np.append(arr, x).
  • np.append does not change the array. It returns a new one, so you must assign it back to the same name.
  • np.arange(n) gives n passes. If the loop variable is not used, it only counts.
Example with made-up rolls
rolls = np.array([])

for i in np.arange(5):
    rolls = np.append(rolls, np.random.randint(1, 7))

rolls

2.10–2.11 · Conclusion

P-Value and Conclusion

  • The histogram shows what chance alone produces. The red dot is the real result.
  • The p-value is the fraction of simulated statistics at least as extreme as the observed one, in the direction of the alternative.
  • Compare it to the cutoff, then state your conclusion about the null in plain, non-technical language.
  • Reading: textbook Chapter 12.1, the section Conclusion of the Test.
