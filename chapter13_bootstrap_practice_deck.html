Steps 1–2 · The Idea

Parameter, Statistic, Estimate

  • A parameter is a number about a whole population, such as its mean. It is usually unknown, because studying everyone is costly.
  • We take a random sample and calculate a statistic. That statistic is our estimate of the parameter.
  • A different random sample would give a different estimate. This is sampling variability.
  • The goal of this assignment: use one sample to describe how much the estimate could vary.

Steps 3 and 6 · New Method: np.percentile

Finding a Percentile in Code

  • A percentile marks a position in sorted data. The 50th percentile is the median.
  • np.percentile(arr, p) returns the p-th percentile of the array arr.
  • Give it a list of percentiles to get several at once.
  • The first input is the array you want the percentile of. Choosing the right array matters.
  • np.percentile may differ a little from the by-hand rule on small data. With thousands of values the difference is tiny.
Example with made-up scores
scores = np.array([62, 70, 74, 81, 85, 90, 95])

np.percentile(scores, 50)
# 81.0

np.percentile(scores, [25, 75])
# array([72. , 87.5])

Resampling
Making new samples from the one we have, and repeating. Steps 4–5.
Review · From Lecture

What Is the Bootstrap?

We have only one random sample, so we cannot see how much a statistic would change from sample to sample. The bootstrap uses that one sample to estimate this variation.

  1. 1Start with the original sample and compute the statistic, such as the sample median. It is our estimate of the population parameter.
  2. 2Treat the original sample as if it were the population.
  3. 3Draw a bootstrap sample from it with replacement, the same size as the original sample.
  4. 4Calculate the same statistic for that bootstrap sample.
  5. 5Repeat many times, often thousands. The statistics form the bootstrap distribution, which shows how much the statistic could vary.
  6. 6Bootstrap percentile method: the 2.5th and 97.5th percentiles of the bootstrap distribution give a 95% confidence interval for the parameter.
Review · A Small Example

Bootstrap Samples, by Hand

  • With replacement means a selected value can be chosen again. Some values appear several times in a bootstrap sample, and others do not appear at all.
  • Each bootstrap sample gives a slightly different median. That spread is the sample-to-sample variation the bootstrap estimates.
  • Four bootstrap samples are far too few for an interval. With thousands, the percentiles are much more reliable.
  • The bootstrap works best when the original sample is large, random, and a good picture of the population, and for statistics like the mean or median. It can do poorly with very small samples, strongly skewed data, or a maximum or minimum.

Step 4 · New Method: Series.sample

Sampling With and Without Replacement

  • series.sample(n, replace=...) draws n values at random from a pandas Series.
  • replace=False: a value, once drawn, cannot be drawn again. Every draw is a different item.
  • replace=True: a value is put back after it is drawn. The same item can appear more than once, and some may never appear.
  • n is how many values to draw. You choose it.
Example with a made-up Series
heights = pd.Series([12, 15, 11, 18, 14, 16])

heights.sample(3, replace=False)
# 3 different items, e.g. 15, 11, 18

heights.sample(3, replace=True)
# items can repeat, e.g. 14, 14, 12

heights.sample(3, replace=True).mean()
# the mean of one resample of 3

Step 5 · Collecting Results

Repeating with a Loop and np.append

  • Start with an empty array: np.array([]).
  • Each pass of the loop, add one result with np.append(arr, x).
  • np.append returns a new array. It does not change the old one, so assign the result back to the same name.
  • Replacing the array with a single number each pass would throw away the earlier results.
Example with the made-up heights
sums = np.array([])

for i in np.arange(4):
    sums = np.append(sums, heights.sample(3, replace=True).sum())

sums
# e.g. array([41., 38., 47., 44.])

Step 6 · From Percentiles to an Interval

The Middle of the Distribution

  • A confidence interval uses the middle of the bootstrap distribution.
  • A middle C% leaves (100 − C) / 2 percent in each tail.
  • The two endpoints are the percentiles at the edges of that middle part.
  • Example: a middle 90% leaves 5% in each tail, so its endpoints are the 5th and 95th percentiles.
Example: a 90% interval
# boot_stats holds many bootstrap statistics
lower = np.percentile(boot_stats, 5)
upper = np.percentile(boot_stats, 95)

Steps 8–9 · Reading the Interval

What an Interval Tells You

  • An interval estimates a population value, such as a population mean. It does not describe where most individual values fall.
  • The confidence level describes the method: over many repeated samples, the method would capture the true value about that often. For any one interval, we usually do not know.
  • Testing a claim: for a two-sided test at the 5% level, reject a claimed value if it is outside the 95% interval.
  • Higher confidence generally gives a wider interval. A larger original sample gives a narrower one.
