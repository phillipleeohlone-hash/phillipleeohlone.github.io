1.0 · The Big Picture

The Parts of a Regression Analysis

  • Fitted values (predictions) come from plugging each x value into the line.
  • The correlation coefficient (r) measures the direction and strength of a linear association.
  • The RMSE (root mean squared error) is the typical size of a prediction error. A residual plot shows whether the errors have a pattern.
  • The slope and intercept describe the regression line itself.
Question 1.0 asks you to put these four parts in the order you would actually do them. Ask yourself, for each step: what would I need to have done already before I could do this one?

1.3–1.4 · Standard Units

Building a DataFrame in Standard Units

  • A value in standard units is (value - average) / SD. Use np.mean for the average and np.std for the SD.
  • Arithmetic on a whole column works on every value at once.
  • pd.DataFrame({'name': values, ...}) builds a DataFrame from columns. The column names in Question 1.3 must match exactly.
  • In standard units the scatter plot has the same shape. Only the numbers on the axes change, so read the ticks.
Example with made-up values

1.6 · The Correlation Coefficient

Computing r

  • Convert both variables to standard units, multiply each pair of values, and average those products. That average is r (Chapter 15.1).
  • It is always between −1 and 1 and has no units.
  • It measures linear association only. A strong curved pattern can still have r near 0.
Multiplying two columns, row by row
pairs = pd.DataFrame({
    'a': np.array([1, 2, 3]),
    'b': np.array([10, 20, 30])})

pairs['a'] * pairs['b']
# 10, 40, 90  (one product per row)

2.1–2.2 · Slope and Intercept

The Regression Line in Original Units

  • In standard units the regression line is predicted y = r × x. The GIVEN cell draws it.
  • Going back to original units stretches the line: horizontally by the SD of x (less steep) and vertically by the SD of y (more steep).
  • The line always passes through (average x, average y). The lab shows how that gives the intercept.
  • The slope is how much the predicted y changes, on average, when x increases by one unit. Its units are units of y per unit of x: here, minutes of waiting per minute of eruption.
Example with made-up numbers
# hours studied (x) and exam score (y)
r = 0.5
x_mean, x_sd = 10, 4
y_mean, y_sd = 70, 12

slope = r * y_sd / x_sd          # 1.5 points per hour
intercept = y_mean - slope * x_mean   # 55

3.1–3.3 · Adding Columns Safely

Predictions and Residuals as Columns

  • A fitted value (prediction) is slope × x + intercept. It works on a whole column at once, so no for loop.
  • df['new column'] = values changes df itself. Section 5 expects faithful to have only its two original columns.
  • So start from faithful.copy(), then add the column to the copy. Do the same with faithful_predictions.copy() for the residuals.
  • A residual (prediction error) is observed value − predicted value. The residuals average 0, so they should add up to about 0.
Example with the made-up shoes DataFrame
new = shoes.copy()
new['feet'] = shoes['height'] / 12

# shoes is unchanged.
# new has one more column: feet

4.1–4.2 · Extrapolation

Predicting Outside the Data

  • The line was fit only to the data in the shaded range.
  • The line keeps going forever, but the relationship may not continue beyond the observed data.
  • Making predictions for x values outside the range of the data is called extrapolation. These predictions may be unreliable.
  • For each prediction, compare the x value with the shortest and longest eruptions in the data, and ask whether it even makes physical sense.

One Line or Two?

  • When the data falls into clusters, you can split it and fit a separate line to each part. Made-up data shown.

  • Within one cluster the x values cover a narrower range, so r is often weaker than for all the data together.

5.2–5.3 · Functions

A Line for Each Cluster

  • slope_of(table, r) and intercept_of(table, r) take a whole DataFrame and its r. Inside, use .iloc[:, 0] for x and .iloc[:, 1] for y.
  • They use the same formulas as Section 2, just written once so they work for any table.
  • predict_wait uses if / else to pick a line. Every branch must return.
Example with made-up shipping rates
def shipping_cost(weight):
    if weight < 10:
        return 2 * weight + 5
    else:
        return 1.5 * weight + 10

shipping_cost(20)   # 40.0
