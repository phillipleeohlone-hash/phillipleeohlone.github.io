Which Expression Is Larger?

Write each equation as a Python expression, assign each to a variable, then use max() to print the larger value.

Expression A
(6 + 2)2 − 33 (5 − 2) × 4
+ 7
Expression B
(3 + 5)2 − 43 2(6 − 2)
Solution
expression_a = ((6 + 2) ** 2 - 3 ** 3) / ((5 - 2) * 4) + 7
expression_b = ((3 + 5) ** 2 - 4 ** 3) / (2 * (6 - 2))

print(max(expression_a, expression_b))
# 10.083333333333334 -- expression_a is larger

Common Bug · Q2.1.3 & Q5.1.1

Off-By-One: np.arange Stops Before the End

np.arange(start, stop, step) never includes stop. Miss it on either end of the range and the array comes up one value short.

Q2.1.3 · multiples of 99, 0 through 9999
np.arange(0, 9999, 99)
# common error: stops before 9999, so it's excluded

np.arange(0, 10000, 99)
# fix: push stop past 9999 to include it
Q5.1.1 · time since start of month
np.arange(1, 31*24*60*60, 3600)
# common error: starts at 1, but midnight is t = 0

np.arange(0, 31*24*60*60, 3600)
# fix: start counting from 0
Common Bug · Q4.1

Filtering Narrows Rows — It Doesn't Hand You The Answer

Q4.1 · Compute the year the world's population first crossed 6 billion, and assign the year to year_x.

Common error
year_x = population[population['Population'] > 6e9]
year_x
# a table of rows, starting in 1999 -- not the year itself
Solution
year_x = population[population['Population'] > 6e9]['Year'].iloc[0]
# pick the Year column, then the first row -- 1999
