Comparisons, random choice, and if/elif/else — letting a program decide what to do based on a value.
1 · Comparison Operators

Comparisons Return Booleans

  • A comparison like <, >, or == evaluates to True or False.
  • == asks whether two values are equal; = assigns a name. They are not the same.
  • Applied to an array, a comparison checks every element and returns an array of booleans.
In [ ]:
result = 10 / 2 == 5
result  # True

np.array([2, 9, 4]) > 3
# array([False,  True,  True])
1.1 · Random Choice and Counting

Random Choice and Counting

  • np.random.choice(arr) picks one item at random; every item is equally likely.
  • Passing a count n draws n items with replacement — an item can be picked again — and returns an array.
  • np.count_nonzero counts the True values in a boolean array, since True is 1 and False is 0.
In [ ]:
nachos = np.array(['cheese', 'salsa',
                   'both', 'neither'])
np.random.choice(nachos, 10)

np.count_nonzero(
    np.array([True, False, True]))

1.2–1.3 · Conditional Statements

Conditional Statements

  • An if statement lets Python choose among alternatives based on whether an expression is true.
  • Conditions are checked in order, top to bottom. Only the first true one runs; the rest are skipped.
  • elif needs an if before it; else runs when nothing above was true.
In [ ]:
def sign(x):
    if x > 0:
        return 'Positive'
    else:
        return 'Negative'

1.4–1.5 · Tables and apply

Applying a Function to a Column

  • pd.DataFrame({ ... }) builds a table; each key becomes a column name.
  • df[col].apply(fn) calls fn once on each value in the column and returns a new Series of the results.
  • Pass the function's name without parentheses — apply does the calling.
In [ ]:
words = pd.DataFrame({'Word': ['cat', 'horse']})
words['Word'].apply(len)

# 1    5

2.1 · Iteration

Iterating Over an Array

  • for <placeholder> in <array>: runs the indented body once for each element.
  • The placeholder name is arbitrary, but pick an informative one and use it consistently in the body.
  • To count as you go, start a variable at 0 and add to it inside the loop.
In [ ]:
num_colors = 0
for color in rainbow:
    num_colors = num_colors + 1
num_colors  # 7 for a 7-item array

2.2 · Simulation

Repeating Code Many Times

  • Sometimes the placeholder's value doesn't matter — only how many times the loop runs.
  • np.arange(n) makes an array of length n, so looping over it repeats the body n times.
  • A simulation repeats a random experiment many times (the trials) and tallies what happens.
In [ ]:
for i in np.arange(5):
    print("Hello, world!")
# printed 5 times; i is never used

Parameters and Statistics

3.2 · Simple Random Samples

Sampling Rows from a Table

  • In a simple random sample without replacement, every row is equally likely to be chosen and none is chosen twice.
  • df.sample(n) returns a new table of n randomly chosen rows. Unlike datascience, pandas samples without replacement by default.
  • Pass replace=True to allow a row to be picked again.
  • np.random.choice picks values out of an array; sample picks rows out of a table.
In [ ]:
full_data.sample(5, replace=True)

full_data.sample(5, replace=False)

4.1 · Simulating Many Trials

Simulating Many Trials at Once

  • First decide what values one trial can take; then np.random.choice(options, n) draws all n trials in a single call — no loop needed.
  • The result is an array, so you can summarize it with the same tools you've already used on arrays.
In [ ]:
coin = np.array(['heads', 'tails'])
flips = np.random.choice(coin, 100)
np.count_nonzero(flips == 'heads')
