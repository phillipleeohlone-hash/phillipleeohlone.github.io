order of operations

Python follows the same order of operations taught in school, plus ** for exponents — 2**3 means 2³. Parentheses override that order, and moving them around can send the result somewhere completely different, as these two lines show.

9+(6*5-(6*3))**2*((2**3)/4*7)  # 2025.0

Names · 1 of 3
assignment statements

An assignment has a name on the left of = and an expression on the right. Python evaluates the right-hand side first, then binds that value to the name — it's a definition, not a claim of equality. Reference a name before it's defined, and you get a NameError.

python
ten = 3 * 2 + 4
ten          # 10

eleven + 8   # NameError: name 'eleven' is not defined
right side first · evaluated, then bound valid names · letters, digits, underscores · can't start with a digit naming · doesn't matter to Python, matters a lot to readers

Calling Functions · 1 of 2
abs() & max()

abs takes one argument and returns its absolute value — the sign is discarded either way. max takes any number of arguments, separated by commas, and returns the largest of them. Both are always available; no import needed.

python
abs(5)              # 5
abs(-5)              # 5
max(2, -3, 4, -5)    # 4
abs · one argument, drops the sign max / min · any number of comma-separated arguments built-in · no import required
