expressions & statements

An expression is self-contained and always evaluates to a value. A statement is a full line of code — some are just expressions, others make something happen, like an assignment statement, which evaluates its right-hand side and binds the result to the name on the left.

Section 1.2 · Variable Renaming
don't shadow built-ins

Every name in Python, including max, can be reassigned. Do it, and the built-in function is gone — the name now points at whatever was assigned to it, until it's deleted or the kernel restarts.

python
max(5, 6, 7)     # 7 -- max is still the built-in function

max = 8          # max now refers to the int 8
max(5, 6, 7)     # TypeError: 'int' object is not callable

del max          # removes the shadow, restores the built-in
before · max is a function after max = 8 · max is an int del max · undoes the reassignment

three ways to import

Importing the whole module keeps everything namespaced behind a dot. Importing specific names — or everything, with * — drops the prefix, at the cost of knowing exactly where a name came from.
