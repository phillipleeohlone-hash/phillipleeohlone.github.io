Defining Functions
The anatomy of a function: name, signature, body, and what return actually does.
1.1–1.2 · Function Anatomy

Defining a Function

  • def, then a name, then a signature in parentheses — the argument names the body gets to use.
  • A colon starts the body; every line inside it must be indented.
  • return is what the function call evaluates to. Names created inside the body disappear once the call ends.
In [ ]:
def to_double(x):
    """Doubles a number."""
    return x * 2

to_double(21)  # 42

1.3–1.4 · Calls on Calls, Print vs. Return

Functions Calling Functions

  • A function's body can call any other function you've already defined — including one you just wrote.
  • print only displays a value; it doesn't hand it back to the caller.
  • A function with no return statement evaluates to None, even if it printed something.
In [ ]:
def shout(word):
    print(word.upper())

result = shout("hi")  # prints HI
result # None -- shout never returned anything

Converting Pay Strings to Numbers

Applying Functions
Functions are values too -- apply calls one on every row of a column at once.
3.1 · Functions as Values

Functions Are Values

  • A function name with no parentheses after it is just a value — like a number or a string.
  • That means you can store it in a variable, or put several of them in an array.
  • You still need parentheses to actually call one you've pulled out.
In [ ]:
some_functions = np.array([max, np.average, len])
some_functions[0](4, -2, 7)  # 4

3.2 · The apply Method

Calling a Function on Every Row

  • df[col].apply(fn) calls fn once for every value in that column and collects the results.
  • It returns a new Series — the original column is left alone.
  • df.copy() makes a new table, so adding a column to it leaves the original untouched.

3.3–3.4 · Computing with a Converted Column

Working with Converted Pay

  • Once a column holds real numbers, ordinary arithmetic and np.average work on it directly.
  • Dividing one converted column by another gives you a proportion, one per row.

Visualizing how values are spread out, not just what they average to.
4.1–4.2 · Plotting a Distribution

Histograms with .hist()

  • df[col].hist() plots the distribution of a numeric column.
  • A histogram shows how spread out the values are — a few CEOs can pull the average up without most of them earning anywhere near it.
  • Boolean indexing plus len(...) lets you count rows above a threshold, to check the histogram against a number.
In [ ]:
compensation["Total Pay ($)"].hist()
